# Day 09: Advanced Analytics - Grouping & Subqueries

### 🎯 Objective
To derive complex business insights by summarizing data patterns using `GROUP BY`, `HAVING`, and executing nested queries (Subqueries).

### 🧠 Key Concepts:
* **GROUP BY:** Aggregating data into meaningful categories (e.g., Total Sales by City).
* **HAVING:** Filtering categorized data (e.g., Cities with total sales > ₹50,000).
* **Subqueries:** Querying within a query to filter data based on dynamic conditions.

### 📊 Business Utility:
* **Segmented Analysis:** Understanding which age groups or cities contribute most to revenue.
* **Complex Filtering:** Identifying products whose selling price is higher than the average selling price of all products.
