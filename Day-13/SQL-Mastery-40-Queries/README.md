# Data-Analyst-Learning-Journey: E-commerce Basic SQL Queries 

## 🎯 Overview
In this sprint, I analyzed an E-commerce schema (`Orders`, `Customers`, `Employees`, `Products`) by solving 40 business-oriented SQL queries. This project demonstrates my proficiency in transforming raw data into actionable insights.

## 🛠️ Key Skills Demonstrated
- **Data Cleaning:** Handled missing values (`NULL`), standardized formats, and resolved IDE-level system restrictions.
- **Filtering & Pattern Matching:** Applied `WHERE`, `BETWEEN`, and `LIKE` for precise data subsetting.
- **Aggregation & Math:** Utilized `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, and `MOD()` to compute metrics.
- **Advanced Logic:** Implemented `SUBQUERIES`, `CONCAT`, and date manipulation (`YEAR`, `MONTH`) to drive business reports.

## 📈 Business Impact
- **Customer Insights:** Identified high-value segments and missing profile data.
- **Sales Intelligence:** Tracked revenue patterns, categorical performance, and seasonal sales trends.
- **Inventory Benchmarking:** Analyzed pricing extremes and product categories.

## 📁 File Structure
- `ecommerce_sprint.sql`: Complete script containing all 40 queries.
- `Dataset_Info`: Schema and table structures used for this analysis.
